## Location Permission Help

Analogue IOT uses location access for live vehicle tracking, trip history, route replay, geofence alerts, and safety monitoring. Background location may be used so tracking and alerts continue when the app is closed or not actively in use.

You can manage location permission from your device settings:

Android:

1. Open Settings.
2. Select Apps.
3. Select Analogue IOT.
4. Select Permissions.
5. Choose Location and update access.

iOS:

1. Open Settings.
2. Select Analogue IOT.
3. Select Location.
4. Choose the preferred location access.

Disabling location may stop live tracking, background tracking, route history, and geofence alerts from working correctly.
